# 📚 Bookable

Explainable book recommendations over `Books.csv` (MERN). Pick one of five algorithms — or compare
them all — and see exactly why each book was recommended.

**Full documentation lives in [`readme/`](readme/README.md)** (requirements, build phases,
architecture, data, algorithms, API, frontend, setup, testing, future work).

```bash
cd server && npm install && npm run import && npm start   # :5050
cd client && npm install && npm run dev                    # :5173
```
